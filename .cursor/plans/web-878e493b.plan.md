# 修复番茄钟和任务管理问题

## 问题概述

检查项目后发现了7个需要修复的问题，这些问题影响了番茄钟的停止流程、任务管理、类型一致性等功能。

## 修复内容

### 1. 修复 FloatingTomatoTimer 停止逻辑

**文件**: `frontend/src/components/FloatingTomatoTimer.tsx`

- 修改 `handleStop` 函数，从直接调用 `stop()` 改为导航到 `/tomato?action=stop`
- 确保停止操作能触发完整的总结对话框流程

### 2. 添加 SimpleTomatoPage URL 参数处理

**文件**: `frontend/src/pages/SimpleTomatoPage.tsx`

- 添加 `useEffect` 监听 URL 参数 `action=stop`
- 当检测到 `action=stop` 时，执行停止流程并显示总结对话框

### 3. 添加清除 currentTask 的逻辑

**文件**: `frontend/src/pages/SimpleTomatoPage.tsx`

- 添加 `useEffect` 监听 `showSummaryDialog`、`isRunning`、`isPaused`
- 当总结对话框显示且计时器已停止时，清除 `currentTask`

### 4. 统一 Task 接口定义

**文件**: `frontend/src/core/store/tomatoStore.ts`

- 在 `Task` 接口中添加 `completedAt?: string` 字段
- 确保所有文件中的 Task 接口定义一致

### 5. 实现快速任务创建功能

**文件**: `frontend/src/pages/SimpleTomatoPage.tsx`

- 添加快速任务创建相关的状态变量（`showQuickTaskForm`, `quickTaskTitle`, `quickTaskPriority`, `quickTaskType` 等）
- 实现 `handleCreateQuickTask` 函数
- 添加快速任务创建 UI 表单

### 6. 修改 handleStart 触发快速任务创建

**文件**: `frontend/src/pages/SimpleTomatoPage.tsx`

- 修改 `handleStart` 函数，当 `currentTask` 为 `null` 时显示快速任务创建表单
- 更新"开始专注"按钮文本，当没有任务时显示"创建任务并开始"

### 7. 修复 FloatingTomatoTimer 语法错误

**文件**: `frontend/src/components/FloatingTomatoTimer.tsx`

- 删除第 213 行的多余分号
