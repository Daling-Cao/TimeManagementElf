# 如何查看您的笔记和总结数据

## 在浏览器控制台查看

打开浏览器开发者工具（F12），在 Console 标签中输入以下命令：

### 查看所有任务和总结
```javascript
const tasks = JSON.parse(localStorage.getItem('tasks') || '[]');
console.log('所有任务:', tasks);
tasks.forEach(task => {
  console.log(`任务: ${task.title}`);
  console.log(`总结数量: ${task.summaries?.length || 0}`);
  if (task.summaries && task.summaries.length > 0) {
    task.summaries.forEach((summary, index) => {
      console.log(`  总结 ${index + 1}:`, summary.summary);
      console.log(`  时间: ${new Date(summary.timestamp).toLocaleString('zh-CN')}`);
      console.log(`  时长: ${summary.duration} 分钟`);
    });
  }
});
```

### 查看所有番茄钟会话
```javascript
const sessions = JSON.parse(localStorage.getItem('tomatoSessions') || '[]');
console.log('所有番茄钟会话:', sessions);
sessions.forEach(session => {
  console.log(`会话 ID: ${session.id}`);
  console.log(`总结: ${session.summary}`);
  console.log(`时间: ${new Date(session.startTime).toLocaleString('zh-CN')}`);
  console.log(`时长: ${session.duration} 分钟`);
});
```

### 导出所有数据（备份）
```javascript
const data = {
  tasks: JSON.parse(localStorage.getItem('tasks') || '[]'),
  tomatoSessions: JSON.parse(localStorage.getItem('tomatoSessions') || '[]'),
  exportTime: new Date().toISOString()
};
const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = `时间管理数据备份_${new Date().toISOString().split('T')[0]}.json`;
a.click();
```

### 导入数据（恢复）
```javascript
// 先读取您备份的 JSON 文件内容，然后执行：
const backupData = { /* 粘贴您的备份数据 */ };
localStorage.setItem('tasks', JSON.stringify(backupData.tasks));
localStorage.setItem('tomatoSessions', JSON.stringify(backupData.tomatoSessions));
console.log('数据已恢复！请刷新页面。');
```

## 数据存储位置

- **物理位置**: 浏览器的 Local Storage
- **存储键名**: 
  - `tasks` - 任务和总结数据
  - `tomatoSessions` - 番茄钟会话记录
  - `tomato-store` - 番茄钟状态（Zustand 持久化）

## 注意事项

⚠️ **重要**: 
- 数据存储在浏览器本地，清除浏览器数据会丢失所有记录
- 建议定期使用上面的导出功能备份数据
- 不同浏览器之间的数据不共享
- 隐私/无痕模式下关闭浏览器后数据会被清除
